**GENRA CHOP 0.19 · GENRA SCHLAG 0.16** for the Akai MPC (OS 3.10.1 plugin SDK, Live III / Gen3).

Install: unzip, copy both folders from `VST2 Plugins/` into `VST2 Plugins/` on the MPC's drive, restart the MPC. Manual: [genra-chop/README.md](https://github.com/Camillowup/genrampc/blob/main/genra-chop/README.md).

**GENRA CHOP 0.19**
- SAVE LOOP: the chop track over the loop length at the current tempo as a WAV (loops without a gap); SAVE WAV is now SAVE CHOP
- A chop's PITCH counts for the chords: bass, melody and pads follow it with NEW
- Rows with < > beside PAT / MODE, M the whole row high, OCT as a key under BASS
- New main page (0.18): smaller display, bigger rows, lists on double tap, M and a lamp per row, UNDO beside NEW ALL, CLEAR with two taps
- Your own chops with GENRA's accompaniment (record with the MPC in PADS), GRID AUTO … 1/16, count-in fix, click-free chops
- SETUP: DIAG (2-minute log), SKIN (coming soon)

**GENRA SCHLAG 0.16**
- Bigger M / S, RANDOM kind, HOLD, ROLL, function fields; new main, STEPS (DRAW / EDIT, COPY / PASTE BAR) and FOLDER pages
- SETUP: DIAG and SKIN

**Both:** a chosen list field or knob gets a red frame, the data wheel steps it.
